# Design Workflow

## 1. Establish need

Define the problem, outcome, consumers, exclusions, risk, and activation gate. Confirm that a normal prompt, deterministic procedure, or simple workflow is insufficient before adding agentic complexity.

## 2. Capture human practice

Describe competent human execution, including inputs, decisions, evidence, outputs, exceptions, and judgments that remain human-accountable.

## 3. Build the artifact map

Identify the primary profile and embedded frameworks, methods, processes, procedures, workflows, protocols, patterns, prompts, skills, tools, and implementations.

## 4. Design agency

Classify each consequential activity as deterministic, agent-reasoned, tool-executed, human-decided, or hybrid. Select orchestration patterns only after dependencies and authority boundaries are explicit.

## 5. Define contracts and state

Specify stage inputs, outputs, evidence, completion, error states, handoffs, stop conditions, checkpoints, durable state, knowledge sources, and recovery.

## 6. Add evaluation and safety

Define representative and adversarial cases, baselines, thresholds, permissions, data boundaries, external effects, escalation, and human approval.

## 7. Package and govern

Create repository interfaces, manifest, conformance map, prompts, skills, adapters, templates, validators, examples, changelog, upgrade guidance, migrations, and decisions as applicable.

## 8. Verify and release

Run deterministic validation and outcome evaluations. Record deviations and unresolved findings. Release only after the declared gate and human approval.
