# Repository Workflow

## Required interfaces

Create or map:

- `README.md` for humans;
- `AGENTS.md` for agents;
- `moda.yaml` for machines;
- `CHANGELOG.md` for evolution.

Map specification, onboarding, invariants, best practices, limitations, upgrades, migrations, decisions, conformance, and audits to authoritative locations.

## Disclosure

Use the canonical disclosure templates. Keep the explanation brief, link to the official MODA repository, and derive version and profile from `moda.yaml`.

## Progressive disclosure

Keep entry points navigational. Put normative rules in the specification, operational procedures in the skill, detailed knowledge in references, machine constraints in schemas, and historical rationale in decisions.

## Validation

Check required files, YAML and JSON syntax, semantic versions, immutable commits, local paths, disclosure markers, package sources, conformance profile, audit shape, and synchronization state.
