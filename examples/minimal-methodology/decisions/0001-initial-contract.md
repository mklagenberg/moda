# DR-0001: Adopt the minimal MODA repository contract

- Status: accepted
- Date: 2026-08-12

## Context

The example needs to demonstrate MODA's minimum repository capabilities without copying the full MODA repository or implying verified conformance.

## Decision

Keep the specification, entrypoints, changelog, roadmap, Decision Records, manifest, conformance profile, and audit fixture as separate minimal artifacts.

## Consequences

The example remains small, while each required capability is explicit and independently addressable.
