# Decision 0016 — Use English for public repository artifacts

- Status: accepted
- Date: 2026-08-12

## Context

MODA is intended for international reuse by humans, agents, package ecosystems, and public contributors. Mixing languages across identifiers, branches, documentation, schemas, and release metadata reduces discoverability and creates inconsistent terminology.

## Decision

Use English for public repository files, file names, identifiers, comments, branches, commits, pull requests, tags, and release metadata. Translations may be distributed as clearly identified derived documentation but do not replace canonical English contracts.

## Consequences

- One canonical vocabulary is shared across tools and communities.
- Contributors may need translation support.
- Local methodology instances may choose another language when their own manifest and audience require it.
