# Changelog

All notable changes to MODA are documented here.

MODA follows Semantic Versioning. A fix is released as a PATCH version when it adds no required behavior.

## [Unreleased]

### Added

- Initial MODA 1.0 framework specification, constitution, taxonomy, design model, repository contract, and governance documentation.
- Machine-readable manifest and JSON Schema.
- Evidence-based conformance profile and immutable self-audit history.
- Deterministic repository validator, tests, and GitHub Actions validation workflow.
- Reusable disclosure, manifest, conformance, and audit templates.
- Minimal methodology example with an explicit unknown conformance claim.
- Versioned MODA operational skill, procedural references, provenance manifest, and installation lock example.
- Decision Records for identity, client-zero adoption, repository interfaces, versioning, non-transitive conformance, and skill synchronization.
